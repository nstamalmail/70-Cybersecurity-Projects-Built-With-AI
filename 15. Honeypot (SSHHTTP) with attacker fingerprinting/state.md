# Application State Documentation

## Current State: Idle

### State Variables
- **ssh_running**: false — SSH honeypot listener status
- **http_running**: false — HTTP honeypot listener status
- **ssh_port**: 2222 — Configured SSH listener port
- **http_port**: 8080 — Configured HTTP listener port
- **session_count**: 0 — Total captured sessions
- **active_campaigns**: 0 — Tracked attacker campaigns
- **threat_level**: LOW — Current threat assessment

### State Transitions
```
IDLE -> RUNNING    (user clicks Start)
RUNNING -> PAUSED  (user clicks Pause)
PAUSED -> RUNNING  (user clicks Resume)
RUNNING -> IDLE    (user clicks Stop)
```

### Data Flow
1. Simulated events generated by timer
2. Events processed through fingerprinting pipeline
3. Data stored in session model
4. GUI updated via Qt signals
5. Reports generated on-demand

### Persistence
- Sessions stored in-memory (dict)
- Export to JSON/CSV/HTML/PDF
- No database required for demo mode
